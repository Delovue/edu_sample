# 国际学生申请条件与流程

本文件规定国际学生各层次项目的学历、年龄与语言要求及申请流程。

1. 学历要求

申请就读本科，需持有高中毕业证书，年龄在25岁以下。

申请就读硕士，需持有本科学历证书，年龄在35岁以下。

申请就读博士，需持有硕士学历证书，年龄在40岁以下。

申请普通进修项目，需至少完成两年本科学习或具备同等学力，年龄在45岁以下。

申请高级进修项目，需持有硕士或硕士以上学历证书，年龄在50岁以下.

申请汉语进修项目需具备高中以上学历。

2. 语言要求

英文授课项目：

申请者需具备良好的英语能力。优先考虑在托福、雅思或其他官方认可的考试中成绩良好以及取得语言能力证书的申请人。

中文授课项目：

理学、工学、经济、管理、医学类学科的申请者需通过汉语水平考试四级（HSK 4）;

文学、教育、法学类学科的申请者，以及临床医学类研究生项目的申请者需通过汉语水平考试五级（HSK 5）。

3. 申请流程

(1). 登录在线申请系统：（网址略）

(2). 上传相关文件，提交申请。

(3). 一旦符合申请要求，你将会收到在线系统发送的提示。请根据要求按时缴纳申请费。

(4). 确认完成缴费后，你的申请材料将会推送至学术审核和前置审核。审核通过者，我们将尽快发出录取通知书和签证申请表。

请注意：上传的文件必须真实清晰有效，不完整的申请将不予受理。
